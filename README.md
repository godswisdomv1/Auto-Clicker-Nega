# Auto Clicker Nega

An Android auto clicker that taps, swipes and waits on a schedule, and can watch the screen and
act when it sees an image, text or colour. No root. Offline first.

Status: under construction, built batch by batch from `docs/BLUEPRINT.md`.

- Application ID: `com.zdmgold.autoclickernega`
- Minimum Android: 11 (API 30)
- Branch flow: every batch lands on `ci-analyser`, and when its check is green it is
  fast-forwarded to `main`.

Build, test and release instructions are finalised in batch B21.
